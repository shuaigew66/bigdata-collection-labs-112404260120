## 第 0 步：学会"截图"这个动作

Windows 有自带的截图工具，两种用法随便挑一种：

**方法 A（推荐，最快）**

1. 键盘按住 `Win`（就是那个 Windows 徽标键）不放，再按 `Shift`，再按 `S`，三个键一起松开；
2. 屏幕会变暗一点点，鼠标变成**十字准星**；
3. 按住鼠标左键，从左上角往右下角**拖一个框**，框住你要截的内容，松开鼠标；
4. 屏幕**右下角会弹出一条通知**，点它；
5. 会打开"截图工具"窗口，里面就是刚截的图；
6. 按 `Ctrl + S`（保存）；
7. 在保存窗口**顶部的地址栏**里粘贴这个路径后按回车：
   `C:\Users\wang\Desktop\lab01\images`
8. "文件名"填 `01_device_api`（对应哪张图就填哪个名字）；
9. "保存类型"保持 **PNG**，点"保存"。

**方法 B**

1. 点开始菜单，搜索 `截图工具`（或"截图和草图"）并打开；
2. 点窗口里的"**新建**"按钮；
3. 同样拖框选取区域，松开；
4. 按 `Ctrl + S` 保存，其余步骤同上。

> 小提示：如果按完 `Win+Shift+S` 忘记点通知了，图其实还在剪贴板里——可以打开"截图工具"，直接按 `Ctrl + V` 粘贴出来，再保存。

> **注意**：截图时**不要把整个桌面都截进去**，也不要截到微信/QQ 等无关窗口。只框住需要证明的那一块内容即可，字要看得清楚。

## 第 1 张图：`01_device_api.png`（证明找到了 Device 的 API）

**要证明的事**：设备页的数据是动态加载的，数据来自 `api/devices` 这个请求，请求参数是 `page` 和 `page_size`。

### 操作步骤

1. 打开浏览器（Chrome 或 Edge 都行），在**地址栏**输入下面这个网址，按回车：

   ```text
   https://115.159.159.82/devices
   ```

   > 如果出现"你的连接不是私密连接"之类的红色警告，点「高级」→「继续前往 115.159.159.82（不安全）」即可。

2. 等页面加载完，你会看到一张"设备资产"表格，里面有 `D00000001`、`循环泵-000001-001` 这样的数据。

3. 按键盘 `F12` 打开**开发者工具**。
   > 按 F12 没反应？试试 `Fn + F12`，或者 `Ctrl + Shift + I`。也可以用鼠标右键点页面空白处 →「检查」。

4. 开发者工具出现后，在它**顶部的一排标签**里找到 **`Network`**（中文版可能叫「网络」），点一下它。

5. 在 Network 下面还有一排小按钮：`All` `Fetch/XHR` `JS` `CSS` `Img` …，点 **`Fetch/XHR`**（这样能把无关的请求过滤掉）。

6. **现在按 `F5` 刷新页面**。
   > ⚠️ 这一步顺序很重要：必须**先打开 Network 面板、再刷新**，否则请求列表是空的，抓不到东西。

7. 刷新之后，Network 的列表里会出现几行请求。找到名字是
   **`devices?page=1&page_size=50`** 的那一行（名字里带 `devices` 就行），**用鼠标点它一下**，它会被选中（变蓝）。

8. 这时右边的区域分成好几块，点最左边的 **`Headers`**（中文「标头」）标签。

9. 在 Headers 里从上往下看，能看到这两段：

   ```text
   General
     Request URL: https://115.159.159.82/api/devices?page=1&page_size=50
     Request Method: GET
     Status Code: 200

   ...（中间是 Response Headers）...

   Query String Parameters
     page: 1
     page_size: 50
   ```

10. **让 Request URL 和 Query String Parameters 都出现在画面里**，然后截图。

11. 保存为 `images\01_device_api.png`。

> **如果开发者工具太窄、字看不全**：点开发者工具右上角的 **`⋮`**（三个竖点）→ `Dock side`（停靠位置）→ 选 **`Dock to bottom`**（停靠到底部），这样会更宽，一次能看清更多内容。
>
> **这一张必须是浏览器的 DevTools**，不能是 Jupyter 的代码截图。

## 第 2 张图：`02_company_source.png`（证明 Company 是静态加载）

**要证明的事**：企业数据是随 HTML 一起返回的——在"查看网页源代码"里能直接搜到企业名字。

### 操作步骤

1. 浏览器**新开一个标签页**，地址栏输入：

   ```text
   https://115.159.159.82/companies
   ```

   回车，等页面加载出来（能看到一排排企业卡片）。

2. 在页面的**空白处**（任意没有链接、没有按钮的地方）**点鼠标右键**，在弹出的菜单里选
   **「查看网页源代码」**（英文是 `View page source`）。

   > ⚠️ **千万别点「检查」/「Inspect」**！那个打开的是 Elements 面板，不是这次要的。这两张图的要求不一样。

3. 浏览器会打开一个**新标签页**，地址栏开头是 `view-source:`，页面里全是密密麻麻的 HTML 代码——这就对了。

4. 在这个源码页面按 `Ctrl + F`，在**右上角**或者**底部**出现的小搜索框里输入：

   ```text
   临港精工001有限公司
   ```

   按回车。

5. 页面会自动滚动到命中的位置，企业名字会被**黄色高亮**标出来。你会看到类似这样的代码：

   ```html
   <article class="company-card" data-company-id="C000001">
     <div class="company-card-top">
       <span class="mono">C000001</span>
       <span class="badge active">运营中</span>
     </div>
     <h2><a href="/companies/C000001">临港精工001有限公司</a></h2>
   ```

6. **截图**。画面里最好能同时看到：地址栏的 `view-source:` 开头、`Ctrl+F` 搜索框里的企业名、以及高亮命中的那段源代码。

7. 保存为 `images\02_company_source.png`。

## 第 3 张图：`03_company_next.png`（证明找到了"下一页"这个元素）

**要证明的事**：页面底部的"下一页"是一个 `<a>` 标签，`href` 指向 `/companies?page=2`。

### 操作步骤

1. 浏览器打开（如果已经开着就直接用）：

   ```text
   https://115.159.159.82/companies
   ```

2. 按 `F12` 打开开发者工具。

3. 点开发者工具顶部的 **`Elements`** 标签（中文版可能叫「元素」）。

4. 点开发者工具**左上角**那个"**方框里有个鼠标箭头**"的小图标。
   > 鼠标悬停在它上面会显示 `Select an element in the page to inspect it`。
   > 也可以直接按快捷键 `Ctrl + Shift + C`。

5. 这时鼠标在页面上移动时，鼠标指到哪个元素，哪个元素就会被**蓝色高亮**。
   把鼠标移动到**页面最底部的「下一页」**两个字上（它在页面很下面，需要先往下滚动到页面底部），"下一页"周围会出现蓝色框。

6. **点击「下一页」这两个字**。

7. 这时 Elements 面板里会有一行代码被选中并高亮，内容类似：

   ```html
   <nav class="pagination" aria-label="企业分页">
     <span>上一页</span>
     <b>1</b>
     <a href="/companies?page=2">下一页</a>
   </nav>
   ```

   被选中的那一行就是 `<a href="/companies?page=2">下一页</a>`。

   > 如果只看到 `<nav ...>` 这一行、看不到里面的 `<a>`：点一下 `<nav>` 左边的小三角 **`▸`** 展开它。

8. **截图**，要能看清：`<nav class="pagination">` 那一行、以及被高亮的 `<a href="/companies?page=2">下一页</a>` 那一行。

9. 保存为 `images\03_company_next.png`。

> **这一张只截 Elements 面板**，不需要截 Python 代码。

## 第 4 张图：`04_validation.png`（JupyterLab 的运行结果）

**要证明的事**：5 项校验指标同时输出，全部通过。

### 4.1 启动 JupyterLab

1. 打开文件夹：

   ```text
   C:\Users\wang\Desktop\lab01
   ```

2. 找到里面的 **`start-jupyterlab.bat`**，**双击它**。

3. 会弹出一个**黑色命令行窗口**，里面滚动一些日志。等大约 5～10 秒，浏览器会**自动打开**一个新页面。

   - 如果浏览器没自动打开：手动打开浏览器，在地址栏输入 `http://localhost:8888/lab` 回车。
   - 如果命令行窗口里报错（或窗口一闪就没了），先告诉我，我帮你排查。

   > ⚠️ **不要关掉那个黑色命令行窗口**！JupyterLab 是靠它运行的，关掉网页就断了。截完图再关。

### 4.2 运行整个 Notebook

5. 在左侧文件列表里**双击 `lab1_html_api.ipynb`**，右边会打开这个 Notebook。

6. 如果弹出让你选 **`Select Kernel`** 的对话框，选 **`Lab1 Python`**，点 Select。

   > 也可以在工具栏找到那个"**两个三角形 `⏩`**"的图标，点它旁边的下拉箭头，选 `Run All Cells`。

8. **等它跑完**。跑的时候单元格左边会显示 `[*]`，跑完变成 `[1]`、`[2]` 这样的数字。
   因为程序要请求 100 次设备接口，大概需要 **1 分钟左右**，请耐心等到全部变成数字。

9. 全部跑完后，**往下滚动到 Notebook 最下面**，找到那个输出 5 行的单元格（代码上面有注释写着"便于截图"），输出内容应该是：

   唯一 company_id: 60
   Device 总数: 5000
   唯一 device_id: 5000

10. **截图**，把这段输出连同上方的代码单元格一起框进去。

12. 截完图后，回到那个黑色命令行窗口，按 `Ctrl + C`，再关闭窗口。
